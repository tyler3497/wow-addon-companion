Death Analyzer

Reads a combat log from /combatlog in game (Logs\WoWCombatLog.txt — a zip of one works too) and shows every player death, pull by pull. Click a death and it expands in place with the killing blow, damage and healing totals, a full event timeline for the window you picked, defensives, and every aura that was up.

Advanced Combat Logging gives HP-after-hit on every line; without it, amounts still parse but HP is missing. Hover any spell name for what it does (defensives from the app's database, other spells from Wowhead when online); clicking a spell opens its Wowhead page. Player names are colored by class, damage is red, healing is green.

About

Tyler's WoW Tools, version 0.1.3.

The addon itself lives in its own repo: tyler3497/wow-gear-audit. This app is separate on purpose, so new tools and features can be added here without touching the addon.

Updater source: src/core/updater.js — pure Node, tested with npm run test:core. Addons are registered in src/core/addons.js — one entry per addon, grouped by game (retail / forever).

Settings

Each game has its own AddOns folder. Retail addons go to …\_retail_\Interface\AddOns, Forever addons to …\_forever_\Interface\AddOns.
