About

Tyler's WoW Tools, version 0.1.2.

The addon itself lives in its own repo: tyler3497/wow-gear-audit. This app is separate on purpose, so new tools and features can be added here without touching the addon.

Updater source: src/core/updater.js — pure Node, tested with npm run test:core. Addons are registered in src/core/addons.js — one entry per addon, grouped by game (retail / forever).

Settings

Each game has its own AddOns folder. Retail addons go to …\_retail_\Interface\AddOns, Forever addons to …\_forever_\Interface\AddOns.
