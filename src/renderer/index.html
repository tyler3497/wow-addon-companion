About

Gear Audit companion app, version 1.1.0.

The addon itself lives in its own repo: tyler3497/wow-gear-audit. This companion app is separate on purpose, so new tools and features can be added here without touching the addon.

Updater source: src/core/updater.js — pure Node, tested with npm run test:core.
